The Making of HypeAura

Behind the design colors and code how the HypeAura website was created step by step.

Design Mockups

We started by making wireframes in Figma to plan out how everything would look. This helped us figure out the layout and spacing before we started coding.

View my wireframe designs on Figma

1. Home page

The home page wireframe shows the hero section at the top with a big background image and diagonal X design. We put a Register Now button right there so people can sign up immediately.

Below the hero theres a Welcome to HypeAura section with some description text about the brand. Then we have the registration form with fields for first name last name mobile number and email address.

Colors: We used black for the navbar to make it look modern and clean. The red Submit button on the form stands out so users notice it. At the bottom theres an About HypeAura section with contact info in the footer.

2. Men page

The men page wireframe shows Welcome UserName at the top so it feels personal when someone logs in. The hero section says Men Collection so customers know exactly what page theyre on.

The products are shown in a grid 4 products per row. Each product card has the image a short description the price BHD XX and an Add to Cart button in red.

Why this works: We put Featured Price Low and Price High sorting options on the right side so customers can organize the products how they want. The grid layout is what people are used to from other shopping sites.

3. Women page

The women page uses the same exact layout as the men page. It has Welcome UserName at the top the hero section with Women Collection and the same product grid.

We kept everything consistent so when users switch between men and women pages they dont get confused. The layout buttons and sorting options are all in the same places.

Design consistency: Using the same structure for both pages makes the site easier to use. Customers already know where everything is without having to look around.

4. New Arrivals page

The New Arrivals page shows the newest products from all categories. At the top under the hero section we added filters MEN WOMEN SHOES BAGS ACCESSORIES so users can filter what they want to see.

The products are displayed in the same grid layout 4 per row with 2 rows showing. At the bottom we added some promotional sections with background images for extra content.

Same layout: We kept the same product grid as the other pages for consistency. The filters at the top are the only new feature on this page so users can narrow down the products.
