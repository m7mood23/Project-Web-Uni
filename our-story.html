Our Story

The journey of building HypeAura together.

Our Journey

Working on this website with three other people Mahmood Thamer Ali and Yousef was honestly a great learning experience. We learned a lot about design coding and how to actually work together as a team without going crazy. Everyone had their own strengths which helped a lot because we could split up the work based on what each person was good at. From the start we all just picked the parts we felt comfortable doing and that made everything go smoother.

Team Roles

Thamer took care of all the images and visual content for the website. He spent a lot of time searching Pinterest and other sites for good quality pictures that would fit our clothing items. He really treated it like we were building an actual online store which was cool. After he found the images he would send them to Ali to put on the website. Thamer picked this job because he's always been into graphic design and he thinks visuals are what make customers want to buy stuff.

Mahmood handled the design mockups and a lot of the technical coding. He made all the Figma wireframes at the beginning which basically showed us where everything should go on all six pages like where the buttons and images and sections would be. He kept asking Dr Abdelhameed Fawzy questions throughout the project to make sure we were doing everything right and following the requirements. Mahmood also did a lot of the JavaScript work especially the form validation part. He made sure the form checked that first and last names had at least 3 characters the mobile number was exactly 8 digits and the email format was correct. He set up localStorage to save user data permanently and sessionStorage to control when the welcome message shows up. This way the users name appears in the navbar on every page after they register. After Ali built the basic website Mahmood went back and refined everything to make it look better. He adjusted button sizes fixed spacing issues and added text shadows to the hero sections so you could actually read the text over the images. He made sure the styling was consistent on all pages which took a while but made the site look way more professional. Mahmood also wrote the explanations for the Making Of page about why we made certain design choices.

Ali was the one who built the foundation of the website. He took the HTML structure and the designs and turned them into an actual working site. Ali wrote the base CSS code added Bootstrap to everything and created the main layout and page structure. He was able to build all six pages pretty quickly which gave us something solid to work with. Ali was really patient when Mahmood kept making changes and refinements to improve things. His coding skills got the website up and running and his work was really important for the whole project.

Yousef worked on extra JavaScript features and tested everything. He added the error messages and the success alert when someone submits the form. Yousef went through all the pages testing every button and link and Bootstrap component to make sure everything worked properly. His testing made sure the site was actually interactive and not just a bunch of static pages.

Challenges We Faced

We talked to each other constantly throughout the project especially when something wasn't working or was confusing. There were definitely moments where the CSS would mess up the HTML layout or the JavaScript needed to be fixed or something didn't look like the mockups. One of the biggest problems we had was getting the form validation to work right and making sure the users name showed up on every page using localStorage and sessionStorage together. Another challenge was making the text on the hero images readable without putting ugly boxes around it. We had to experiment with different text shadow styles and overlay transparency until it looked good. We also had to be really careful that our mockups were actual Figma wireframes and not just screenshots of the finished website because the professor said that would be zero marks. Whenever we ran into an issue we would talk about it as a group and figure out how to fix it together. Working as a team definitely made the final result better than if we tried to do everything alone.

What We Learned

This project taught us how to plan design and build a complete website from start to finish while splitting up the work between four people. We learned that asking questions early saves you from running into problems later. We figured out that Bootstrap makes styling way faster and keeps everything looking consistent across different pages. JavaScript is what makes a website interactive instead of boring and localStorage with sessionStorage let you save user info and control what displays on the screen. We also learned you need patience and attention to small details when youre polishing a design to make it user friendly. Following the project requirements exactly is really important especially things like having exactly six pages proper form validation and making sure you use actual wireframes not screenshots. But the most important thing we learned is that communication and teamwork are essential when youre doing a group project. Everyone brought something different to the table and when we put it all together we ended up with a website were actually proud of that meets all the requirements.
